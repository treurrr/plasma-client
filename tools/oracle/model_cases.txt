# Pose cases for ModelOracle: one line per case, "<layer> <field>=<value> ...",
# read by both ModelOracle.java and model_probe.cpp so the two stay in step.
#
# The fields are MobState's own names; the oracle sets the matching field of
# the layer's vanilla render state. An animation state's value is the tick it
# started on, and leaving it out leaves it stopped. Cases must stay grouped by
# layer: both sides build one model per run of a layer and pose it case after
# case, which is what lets a hidden part stay hidden the way the game does.
#
# Every case a mob's own state does is in here: a creeper swelling, a sheep
# eating, a wolf shaking, a cat lying down, a horse rearing, a fox pouncing,
# an armadillo rolling up, a breeze sliding, a copper golem with a full hand.
